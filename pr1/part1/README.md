# Практическая работа № 1 — часть 1

Пять самостоятельных программ на Java: сумма и среднее элементов массива; ввод массива и поиск суммы, минимума и максимума с циклами `while` и `do while`; аргументы командной строки; первые десять членов гармонического ряда; факториал через метод класса.

Откройте репозиторий как проект в IntelliJ IDEA и запускайте нужный класс `Task1`–`Task5`. Для `Task3` укажите аргументы в конфигурации запуска. Для `Task2` и `Task5` вводите данные в консоли. Факториал ограничен диапазоном 0–20, чтобы результат помещался в тип `long`.
